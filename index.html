담당 스킬 3종

game-blueprintP0 · P1 · P2

새 웹게임 착수, 기존 게임의 다음 호 이식, 대규모 리메이크 기획을 시작할 때 사용한다.

전문 보기

새 웹게임 착수, 기존 게임의 다음 호 이식, 대규모 리메이크 기획을 시작할 때 사용한다. "새 게임 만들자", "○호 착수", "이 게임 이식하자", "기획서 써줘", "이거 게임으로 만들어줘", "리메이크" 같은 요청에서 발동. P0 컨셉 → P1 그레이박스 재미 판정 → P2 규격 동결(아트 바이블·에셋 대장·기술 규격) 순서로 진행하며, 사용자 승인 전에는 게임 코드를 한 줄도 쓰지 않는다.

game-assetP3 · P5

게임 에셋을 새로 만들거나, 제미나이 등으로 생성 발주하거나, 기존 에셋을 교체·표준화·업스케일할 때 사용한다.

전문 보기

게임 에셋을 새로 만들거나, 제미나이 등으로 생성 발주하거나, 기존 에셋을 교체·표준화·업스케일할 때 사용한다. "캐릭터 그려야 해", "배경 만들자", "이 이미지 넣어줘", "에셋 교체", "제미나이에 뭐라고 넣을까", "발주서 써줘", "포즈 매핑해줘", "이거 키잉해줘" 같은 요청에서 발동. 컨셉 레퍼런스를 먼저 확정하고 씬을 그림에 맞추며, 발주 규격 위반 소재는 가공하지 않고 재발주한다.

game-verifyP4 · P6 · P7

게임 라운드를 끝냈을 때, 아티팩트 게시 직전, 또는 검수·QA·회귀 확인을 요청받았을 때 사용한다.

전문 보기

게임 라운드를 끝냈을 때, 아티팩트 게시 직전, 또는 검수·QA·회귀 확인을 요청받았을 때 사용한다. "라운드 끝났어", "검수해줘", "게시해도 돼?", "다 됐나 확인", "QA", "테스트 돌려줘", "완료 보고" 같은 요청에서 발동. 완료 기준 체크리스트와 테스트를 1:1로 대응시켜 전부 통과할 때까지 자가 수정하고, 오케스트레이터 육안 관문을 통과한 뒤에만 사용자에게 완료를 보고한다.
