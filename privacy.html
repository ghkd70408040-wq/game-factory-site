개인정보처리방침

시행일 2026년 9월 9일 · 최종 수정 2026년 9월 9일
적용 대상: 안드로이드 앱 com.ghkd.tentwin 및 웹 버전

이 게임은 개인정보를 수집하지 않습니다.

계정도, 로그인도, 광고도, 분석 도구도 없습니다. 게임 진행도와 설정은 이용자의 기기 안에만 저장되며 어디로도 전송되지 않습니다.

1. 수집하는 개인정보

없습니다. 텐트윈 젤리팡 월드는 이용자의 이름, 이메일 주소, 전화번호, 생년월일, 성별, 위치, 연락처, 사진, 기기 식별자, 광고 ID 등 어떠한 개인정보도 수집하거나 요구하지 않습니다.

회원가입 절차가 없고 로그인 화면이 없으며, 개인정보를 입력할 수 있는 입력란 자체가 존재하지 않습니다.

2. 기기에 저장되는 정보

게임을 편하게 이어 하기 위해 아래 정보가 이용자 기기의 브라우저 저장소 (localStorage) 에 저장됩니다.

  • 게임 진행도 — 열린 스테이지, 최고 점수, 별 획득 현황 등
  • 게임 설정 — 소리·진동 켜짐 여부, 화면 설정 등

이 정보는 이용자의 기기를 벗어나지 않습니다. 개발자를 포함해 누구도 이 값을 열람할 수 없으며, 외부 서버로 전송되지 않습니다. 이 게임에는 이용자 데이터를 받는 서버가 존재하지 않습니다.

3. 개인정보의 제3자 제공 및 처리위탁

없습니다. 수집하는 개인정보가 없으므로 제3자에게 제공하거나 처리를 위탁하는 일도 없습니다. 국외로 이전되는 개인정보 역시 없습니다.

4. 광고 및 분석 도구

이 게임에는 광고가 없습니다. 광고 네트워크 SDK를 포함하지 않았습니다.

또한 Google Analytics 등 어떤 분석·통계 도구도 사용하지 않습니다. 비정상 종료 로그를 수집하는 크래시 리포터도 넣지 않았습니다. 이용자가 어떤 화면을 봤는지, 몇 판을 했는지 개발자는 알 수 없습니다.

5. 쿠키

이 게임은 쿠키를 사용하지 않습니다. 위 2항에서 설명한 localStorage 만 사용하며, 이는 쿠키와 달리 네트워크 요청에 실려 서버로 전송되지 않는 기기 내 저장 방식입니다.

6. 네트워크 통신

앱은 게임을 이루는 정적 파일(HTML, CSS, 이미지, 소리)을 내려받기 위해서만 인터넷에 접속합니다. 이용자에 관한 데이터를 보내지는 않습니다. 한 번 내려받은 뒤에는 오프라인 상태에서도 게임을 즐길 수 있습니다.

안드로이드 앱에 관한 안내. 이 앱은 웹 게임을 감싼 TWA(Trusted Web Activity) 방식으로, 화면을 그리는 주체는 이용자 기기에 설치된 Chrome 브라우저입니다. Chrome 자체의 동작(브라우저 자체 통계, 안전 브라우징 등)은 Google 의 정책에 따르는 것이며 본 게임이 수집하는 정보가 아닙니다. 해당 내용은 Chrome 및 Google 의 개인정보처리방침을 참고해 주세요.

7. 이용자의 권리 — 저장된 정보를 지우는 방법

기기에 저장된 진행도·설정은 이용자가 언제든지 직접 삭제할 수 있습니다.

사용 형태삭제 방법
안드로이드 앱 설정 → 애플리케이션 → 텐트윈 젤리팡 월드 → 저장공간 → 데이터 삭제
또는 앱 삭제(삭제하면 진행도도 함께 지워집니다)
웹 브라우저 브라우저 설정 → 개인정보 보호 → 사이트 데이터 삭제 에서 해당 사이트 선택
서버에 남은 정보 없습니다. 서버가 존재하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

삭제한 진행도는 복구할 수 없습니다. 개발자가 보관하는 백업이 없기 때문입니다.

8. 아동의 개인정보

이 게임은 만 13세 미만 아동을 주된 대상으로 설계되거나 홍보되지 않았습니다. 다만 이 게임은 나이와 무관하게 누구의 개인정보도 수집하지 않으므로, 아동의 개인정보가 수집·이용되는 일도 없습니다. 아동이 이 게임을 이용하더라도 개인정보가 외부로 전달되지 않습니다.

9. 개인정보의 안전성 확보

개인정보를 수집하지 않으므로 유출될 개인정보가 존재하지 않습니다. 게임은 https:// 로 제공되어 파일 전송 구간이 암호화됩니다.

10. 방침의 변경

이 방침이 바뀌는 경우, 변경된 내용과 시행일을 이 페이지에 게시합니다. 수집 항목이 늘어나는 등 이용자의 권리에 중대한 영향을 주는 변경은 시행일 최소 7일 전에 이 페이지에 미리 알립니다. 페이지 상단의 시행일·최종 수정일로 최신 여부를 확인하실 수 있습니다.

Privacy Policy

Effective 9 September 2026 · Last updated 9 September 2026
Applies to the Android app com.ghkd.tentwin and the web version.

This game collects no personal data.

There is no account, no sign-in, no advertising and no analytics. Your progress and settings are stored only on your own device and are never transmitted anywhere.

1. Personal data we collect

None. TenTwin Jellypang World does not collect or ask for your name, email address, phone number, date of birth, gender, location, contacts, photos, device identifiers or advertising ID. There is no sign-up, no login screen, and no field in which personal data could be entered.

2. Data stored on your device

So that you can pick up where you left off, the following is stored in your browser's localStorage on your own device:

  • Game progress — unlocked stages, high scores, stars earned
  • Game settings — sound and vibration on/off, display preferences

This information never leaves your device. Nobody, including the developer, can read it, and it is not sent to any server. This game has no server that receives user data.

3. Sharing with third parties

None. Because no personal data is collected, none is shared with, sold to, or processed by third parties, and none is transferred to other countries.

4. Advertising and analytics

The game contains no advertising and includes no ad network SDK. It also uses no analytics tools such as Google Analytics, and no crash reporting SDK. The developer cannot see which screens you viewed or how many rounds you played.

5. Cookies

This game does not use cookies. It uses only the localStorage described in section 2, which — unlike a cookie — is never attached to network requests or sent to a server.

6. Network activity

The app connects to the internet only to download the static files (HTML, CSS, images, audio) that make up the game. It sends no data about you. Once loaded, the game can be played offline.

About the Android app. The app is a Trusted Web Activity (TWA) that wraps the web game, so the screen is rendered by the Chrome browser installed on your device. Chrome's own behaviour (its own telemetry, Safe Browsing and so on) is governed by Google's policies and is not data collected by this game. Please refer to the Chrome and Google privacy policies for that.

7. Your rights — how to delete stored data

You can delete the progress and settings stored on your device at any time.

How you playHow to delete
Android app Settings → Apps → TenTwin Jellypang World → Storage → Clear data
or simply uninstall the app (uninstalling also removes your progress)
Web browser Browser settings → Privacy → Clear site data for this site
Data held on a server None. There is no server, so no deletion request process is needed.

Deleted progress cannot be restored, because the developer keeps no backup of it.

8. Children's privacy

This game is not designed for or marketed to children under 13. That said, the game collects no personal data from anyone regardless of age, so no child's personal data is ever collected or used. Nothing is transmitted off the device even when a child plays.

9. Security

Since no personal data is collected, there is no personal data that could be leaked. The game is served over https://, so files are encrypted in transit.

10. Changes to this policy

If this policy changes, the change and its effective date will be posted on this page. A change that materially affects your rights — for example, if any data collection were introduced — will be announced here at least 7 days before it takes effect. The effective and last-updated dates at the top of this page show whether you are reading the current version.
